# Defensive Driving Seminar v19

### What changed
- Mobile-first, app-like public seminar page.
- Full name + mobile are the only required registration fields.
- Email is optional.
- Date of birth has been removed from the public form.
- Driving licence number remains optional under Additional details.
- Compact cards, larger touch targets, fixed mobile navigation and responsive booking flow.
- Booking management remains available using Booking ID + mobile.
- Admin seminar page remains the venue check-in / participant management area.

### Supabase
If v18 is already installed, run:
`defensive-seminar-mobile-redesign-v19.sql`

For a fresh setup, use the updated `defensive-driving-seminar.sql`.

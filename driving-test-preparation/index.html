Key preparation areas

Driving-test preparation path

Test preparation works best when it is treated as a complete driving-skill review rather than a last-minute checklist. Revisit cockpit drill, moving off and stopping, gear changing, road positioning, junctions, reversing, parking, roundabouts and traffic signals, then practise applying those skills calmly.

The 25-lesson Learning Hub, video classes and bilingual mock test can support revision alongside practical instruction. The mock test currently contains 30 questions, has an 18/30 pass mark and allows 20 seconds for each question.

HPT v58 - Result UI + Evidence Reliability
- Removed clip-by-clip marks from the main result page.
- Main result now focuses on total score/status and provides a prominent VIEW DETAILED RESULT action.
- Secondary result actions are arranged separately for cleaner desktop/mobile presentation.
- Detailed result redesigned as compact clip/hazard evidence rows with smaller thumbnails.
- Response image is shown only when a candidate response exists; missed hazards show no response image.
- Detailed video frame capture no longer forces CORS, improving local testing.
- PDF video frame capture no longer forces CORS; thumbnail fallback remains for unavailable frames.
- Cache-busting versions updated to 58.
